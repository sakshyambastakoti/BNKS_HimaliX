## 1. Two-Way Dynamic Handshake Sequence

Because standard Bluetooth or Wi-Fi Direct protocols suffer from device-pairing latency and permission issues, OffPay utilizes **Two-Way Optical QR Code Transmission**.

```mermaid
sequenceDiagram
    autonumber
    actor Receiver as Receiver (Bob)
    actor Sender as Sender (Alice)

    Note over Receiver: Step 1: Request Generation
    Receiver->>Receiver: Enter amount (e.g. NPR 500)
    Receiver->>Receiver: Generate random 16B nonce
    Receiver->>Sender: Display "Request QR" (OFFPAY_REQUEST)

    Note over Sender: Step 2: Voucher Assembly & Signing
    Sender->>Sender: Scan Request QR
    Sender->>Sender: Select bonds matching NPR 500
    Sender->>Sender: Hash payload with SHA-256
    Sender->>Sender: Sign with Alice's Private Key (Ed25519)
    Sender->>Sender: Mark bonds as 'spent' in SQLite
    Sender->>Receiver: Display "Payment QR" (OFFPAY_PAYMENT)

    Note over Receiver: Step 3: Offline Verification
    Receiver->>Receiver: Scan Payment QR
    Receiver->>Receiver: Verify Server Signature on each Bond
    Receiver->>Receiver: Verify Sender Signature with Alice's Public Key
    Receiver->>Receiver: Validate Nonce match & Amount
    Receiver->>Receiver: Save to SQLite (status = 'pending_sync')
    Note over Receiver,Sender: Transaction Complete (0.0s Internet)
```

## 2. JSON Payload Specifications

### 2.1 Request QR Payload (`OFFPAY_REQUEST`)
Generated by the receiver to declare the desired transaction amount:

```json
{
  "type": "OFFPAY_REQUEST",
  "receiverId": "usr-b2c3d4e5-f6a7-8901-abcd-ef1234567890",
  "receiverName": "Sita Devi",
  "amount": 500,
  "currency": "NPR",
  "timestamp": "2026-08-22T10:15:30.000Z",
  "nonce": "e4a78c1b9f023d45"
}
```

## 3. Density & Error Correction Optimization
* **Encoding Format**: Raw UTF-8 Minified JSON.
* **QR Version & Correction**: Standard Version 9–11 QR with **Level L (7%) error correction** to ensure the payload stays under 450 characters.
* **Scan Latency**: Scans within **150ms–300ms** on standard smartphone cameras under low-light or outdoor sunlight.
