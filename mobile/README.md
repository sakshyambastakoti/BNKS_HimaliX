# OffPay Mobile App (Expo / React Native)

Welcome to the **OffPay (HimaliX)** mobile application — an offline, off-grid peer-to-peer payment system built with Expo, React Native, and TypeScript.

---

## 🚀 How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npx expo start
```

### 3. Open the App
- **Phone (Expo Go)**: Scan the QR code with Expo Go (Android) or Camera (iOS).
- **Web Browser**: Press `w` in the terminal or run `npm run web`.
- **Android Emulator**: Press `a` in the terminal or run `npm run android`.
- **iOS Simulator**: Press `i` in the terminal or run `npm run ios`.
